# 一服 — Digital Ritual

指を引いて、離す。煙の行方を眺める、小さな間。

黒背景の横顔と、流体シミュレーションで拡散する煙を眺めるブラウザアプリです。

## 操作

- 下のボタンを押したまま横にドラッグすると吸気します。
- 指を離すと煙を吐きます。長く引くほど長く煙が出ます。
- PCではスペースキーまたはEnterキーの長押しでも操作できます。
- 吸うほどタバコが短くなり、火種が先端に追従します。
- 満足感が100になると「余韻」に移ります。「もう一度」で再開できます。

満足感は演出上の数値です。禁煙効果を示すものではありません。

## 実装

HTML / CSS / JavaScriptのみ。ビルド不要。外部API・解析・ログインは使用しません。
煙は2D格子上の移流・圧力投影・浮力・渦度によるシミュレーションです。人物はAI生成した2枚の静止画を切り替えています。

## ローカルで開く

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開いてください。

## 公開

Cloudflare Pagesではビルドコマンドを空欄、出力ディレクトリを `.` に設定してください。GitHub Pagesでは `main` ブランチの `/ (root)` を公開します。
